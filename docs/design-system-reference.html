Design system

One typeface, one green, soft neutral grounds and rounded white cards. Every text pair below meets WCAG AA. Ratios are against the background each color is used on.

Forms

Booking runs through Calendly, so the site has no forms at launch. These styles are for any form added later, and the colors to set in Calendly's own styling so the popup matches.

Enter a full work email, like name@company.com.

Focus state: 2px green border plus a 3px tint ring.

Field rules

Label above the field, always visible. Never use placeholder text as the label.

Field: 48px tall, 17px text, 1px #8A968F border, radius 12.

Error: 2px #A3301B border and a message under the field that says how to fix it.

Calendly styling

Button and link color #1F5C46, text color #17211C, background #FFFFFF. Calendly only applies custom colors on paid plans.

Copy rules

Plain words in headings and card copy. Technical terms go in small print and expanders.

Name tools as examples and end the list with "and more".

No prices for work that scales with headcount or apps.

No em dashes, no emojis, no invented numbers, clients or badges.

Leavers lose access "the same day" everywhere.

Icons: inline stroke SVG, 2px, green on green tint.
